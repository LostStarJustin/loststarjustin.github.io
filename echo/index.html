你需要一台服务器 / You need a server

Echo 不提供公共服务器。登录页要填的服务器地址来自你或你的组织自己部署的 Echo 服务器，账号由该服务器的管理员创建，app 内没有注册功能。

Echo offers no public server. The address on the login screen is your own (or your organisation's) Echo server; accounts are created by its administrator and there is no in-app sign-up.

自托管搭建指南 / Self-hosting guide

一台有公网 IP 的 Linux 机器加 Docker，约十分钟。服务器与客户端请保持同一版本。
One Linux machine with a public IP and Docker, about ten minutes. Keep server and clients on the same version.

验证签名 / Verify the signature

macOS 版由 Apple Developer ID 证书签名并经 Apple 公证（Notarization）。Apple 不提供公证徽章，但你可以在自己的 Mac 上验证：

The macOS build is signed with an Apple Developer ID certificate and notarized by Apple. Apple issues no badge for notarization, but you can verify it yourself:

spctl -a -vv -t exec /Applications/Echo.app
#   → accepted  source=Notarized Developer ID
codesign -dvv /Applications/Echo.app
#   → Authority=Developer ID Application: …

Android 版由固定的正式密钥签名，证书 SHA-256 指纹以 39:1D:74:43 开头：apksigner verify --print-certs Echo-0.29.6-android.apk。Windows 版暂未签名。
The Android build is signed with a fixed release key (certificate SHA-256 starts with 39:1D:74:43). The Windows build is not signed yet.
